

## 📌 Project Overview

## 🚀 Features

- 🎯 Multiple-choice quiz questions
- ✅ Instant answer validation
- 📊 Automatic score calculation
- 🔄 Restart quiz option
- ⏭️ Next question navigation
- 📱 Responsive and mobile-friendly design
- 🎨 Clean and modern user interface
- ⚡ Fast and lightweight application
- 🏆 Final score display

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive design
- **JavaScript (ES6)** – Quiz logic and interactivity

## 💻 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in **Visual Studio Code** or any code editor.
3. Open `index.html` in your web browser.
4. Start answering the quiz questions.
5. Check your final score after completing the quiz.

## 🎮 How to Use

1. Start the quiz.
2. Read each question carefully.
3. Select one answer from the available options.
4. Click the **Next** button.
5. Continue until all questions are completed.
6. View your final score.
7. Click **Restart Quiz** to play again.

## 🎯 Objective

The main objective of this project is to create an engaging and user-friendly quiz application while practicing:

- JavaScript DOM manipulation

- Conditional statements
